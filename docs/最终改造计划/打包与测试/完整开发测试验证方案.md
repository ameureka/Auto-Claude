## 二、项目初始化配置 (从零开始)

### 2.1 系统前置要求

| 组件 | 版本要求 | 安装方式 |
|------|----------|----------|
| **Python** | 3.12+ | `brew install python@3.12` (macOS) |
| **Node.js** | 24+ | `brew install node` 或 [nodejs.org](https://nodejs.org) |
| **npm** | 10+ | 随 Node.js 安装 |
| **Git** | 任意 | `brew install git` (macOS) |
| **CMake** | 最新 | `brew install cmake` (Graphiti 依赖需要) |
| **Claude Code CLI** | 最新 | `npm install -g @anthropic-ai/claude-code` |

**验证安装：**
```bash
python3 --version    # Python 3.12.x
node --version       # v24.x.x
npm --version        # 10.x.x or 11.x.x
git --version        # git version 2.x.x
cmake --version      # cmake version 3.x.x
claude --version     # Claude Code version
```

### 2.2 克隆项目

```bash
# 克隆仓库
git clone https://github.com/AndyMik90/Auto-Claude.git
cd Auto-Claude
```

### 2.3 一键安装所有依赖 (推荐)

```bash
# 一键安装 (后端 + 前端)
npm run install:all
```

### 2.4 手动安装后端依赖

如果一键安装失败，手动执行：

```bash
cd apps/backend

# 方式 A: 使用 uv (推荐，更快)
uv venv && uv pip install -r requirements.txt

# 方式 B: 使用标准 Python
python3 -m venv .venv
source .venv/bin/activate   # macOS/Linux
# .venv\Scripts\activate    # Windows
pip install -r requirements.txt

# 安装测试依赖
pip install -r ../../tests/requirements-test.txt
```

### 2.5 手动安装前端依赖

```bash
cd apps/frontend

# 安装 Node.js 依赖
npm install

# 如遇权限问题
sudo chown -R $(whoami) ~/.npm
npm install
```

### 2.6 环境变量配置 (.env)

**复制示例文件：**
```bash
cd apps/backend
cp .env.example .env
```

**编辑 `.env` 文件，配置认证 (三选一)：**

#### 方法 1: OAuth Token (推荐)

```bash
# 运行 Claude Code 设置命令
claude setup-token

# Token 会自动保存到 macOS Keychain
# 或者手动添加到 .env:
CLAUDE_CODE_OAUTH_TOKEN=sk-ant-oat01-xxxxx
```

#### 方法 2: API Key (直接计费)

```bash
# 在 .env 中添加
ANTHROPIC_API_KEY=sk-ant-api03-xxxxx

# ⚠️ 警告: 费用直接计入你的 Anthropic 账户
# 设置预算: https://console.anthropic.com/
```

#### 方法 3: Proxy/Enterprise (ProxyCast)

```bash
# 在 .env 中添加两个变量
ANTHROPIC_AUTH_TOKEN=pc_xxxxx
ANTHROPIC_BASE_URL=http://127.0.0.1:8999
```

### 2.7 可选配置

**.env 其他重要配置项：**

```bash
# 模型覆盖 (默认: claude-opus-4-5-20251101)
# AUTO_BUILD_MODEL=claude-opus-4-5-20251101

# Git 默认分支
# DEFAULT_BRANCH=main

# 调试模式
# DEBUG=true
# DEBUG_LEVEL=2

# Linear 集成 (项目管理)
# LINEAR_API_KEY=lin_api_xxxxx

# Graphiti 记忆层 (跨会话上下文)
# GRAPHITI_ENABLED=true
# OPENAI_API_KEY=sk-xxxxx  # Graphiti 需要 OpenAI/Ollama
```

### 2.8 Pre-commit Hooks 设置 (可选但推荐)

```bash
# 安装 pre-commit
pip install pre-commit

# 安装 Git hooks
pre-commit install

# 验证
pre-commit run --all-files
```

### 2.9 验证初始化成功

```bash
# 1. 验证后端
cd apps/backend
source .venv/bin/activate  # 如果使用虚拟环境
python -c "from core.auth import get_auth_token; print('✅ Backend OK' if get_auth_token() else '❌ No token')"

# 2. 验证测试
python -m pytest ../../tests/test_auth_properties.py -v --tb=short

# 3. 验证前端可启动
cd ../frontend
npm run dev
# 应该打开 Electron 窗口
```

### 2.10 初始化检查清单

| 检查项 | 命令 | 预期结果 |
|--------|------|----------|
| Python 版本 | `python3 --version` | 3.12.x |
| Node.js 版本 | `node --version` | v24.x.x |
| 后端依赖 | `cd apps/backend && pip list \| head` | 显示已安装包 |
| 前端依赖 | `cd apps/frontend && npm list --depth=0` | 无错误 |
| 认证配置 | 运行上述验证命令 | ✅ Backend OK |
| 测试通过 | `python -m pytest tests/` | 全部绿色 |

在开始前确认认证状态：

```bash
cd /Users/ameureka/Desktop/ai_infra_ameureka/Auto-Claude/apps/backend

python -c "
from core.auth import get_auth_token, get_token_type, get_auth_token_source, validate_proxy_config

token = get_auth_token()
if token:
    print(f'✅ Auth: {get_auth_token_source()}')
    print(f'✅ Mode: {get_token_type(token).upper()}')
    is_valid, err = validate_proxy_config()
    print(f'✅ Proxy: {\"PASS\" if is_valid else \"FAIL - \" + err}')
else:
    print('❌ No token - configure .env first')
"
```

**预期输出 (Proxy 模式):**
```

✅ Mode: PROXY
✅ Proxy: PASS
```

**配置：** 设置无效的 Token 值

**预期行为：**
- Agent 启动时 API 返回认证错误
