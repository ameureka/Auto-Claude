# Auto-Claude 费用与授权专题讨论

**日期**: 2025-12-22
**分析对象**: Auto-Claude 商业模型与使用成本

---

## 1. 软件获取成本 (Software Cost)

**Auto-Claude 软件本身是完全免费且开源的。**
- **许可证**: AGPL-3.0。
- **说明**: 你可以自由地克隆、修改和分发其代码，无需向作者支付版权费。

---

## 2. 核心运行成本 (Core Dependencies)

尽管软件免费，但其核心功能依赖于 **Claude Code CLI**，这产生了主要的订阅费用。

### 2.1 官方推荐路径：订阅制
- **要求**: 必须拥有 **Claude Pro** 或 **Claude Max/Team** 订阅。
- **费用**: 约 **$20/月**。
- **优势**: 包含在订阅配额内，无需额外支付高昂的 API 费用，适合日常开发。

### 2.2 魔改路径：API 按量计费
- **要求**: 使用标准 `ANTHROPIC_API_KEY`（需修改源码，详见《魔改讨论》文档）。
- **费用**: **动态计费**（按 Token 消耗）。
- **风险**: Agent 模式下 Token 消耗极快（包含大量的上下文重复读取和多次思考），如果不加控制，可能会产生远超 $20/月的账单。

---

## 3. 辅助功能成本 (Optional Components)

### 3.1 记忆系统 (Graphiti)
- **Ollama 路径**: 如果配置为本地运行，**免费**（仅消耗个人电脑算力）。
- **OpenAI/Voyage 路径**: 如果使用云端 Embedding 模型，按向量化条数扣费，通常费用较低（几美分到几美金不等）。

### 3.2 第三方集成
- **GitHub**: 使用 GitHub CLI 认证，**免费**。
- **Linear**: 基础版免费，企业级高级功能可能涉及费用。

---

## 4. 总结：我该准备多少钱？

| 角色 | 推荐方案 | 预估月支出 |
| :--- | :--- | :--- |
| **标准开发者** | Claude Pro 订阅 + 本地 Ollama 记忆 | $20 |
| **重度 AI 极客** | Claude Pro 订阅 + OpenAI Embedding | $20 + $2 |
| **去订阅化/企业级** | API Key 模式 + 本地/云端记忆 | $0 订阅 + $50~200 API 费 (视使用强度) |

---

## 5. 结论

对于绝大多数个人用户，**$20 的订阅费是“入场券”**。魔改支持 API Key 虽然技术可行，但更适合那些已有大量 API 额度或需要绕过订阅限制的企业用户。
