# 代理终端 (Agent Terminals)

代理终端页面让您实时观察 AI 代理的工作过程。

---

## 界面布局

```
┌────────────────────────────────────────────────────────────┐
│ Terminal 1: Planner    │ Terminal 2: Coder     │ + New    │
├────────────────────────┼───────────────────────┼──────────┤
│                        │                       │          │
│ [Agent 输出日志]       │ [Agent 输出日志]      │          │
│                        │                       │          │
│ > 分析项目结构...      │ > 实现登录功能...     │          │
│ > 发现 React 组件      │ > 创建 Login.tsx     │          │
│ > 制定实现计划...      │ > 添加样式文件...     │          │
│                        │                       │          │
└────────────────────────┴───────────────────────┴──────────┘
```

---

## 终端类型

| 终端 | 用途 | 何时出现 |
|------|------|----------|
| **Planner** | 规划实现方案 | 任务开始时 |
| **Coder** | 编写代码 | 规划完成后 |
| **QA Reviewer** | 验证代码质量 | 编码完成后 |
| **QA Fixer** | 修复问题 | QA 发现问题时 |

---

## 交互控制

### 中断执行

- **Ctrl+C (一次)**: 暂停并等待输入
- **Ctrl+C (两次)**: 立即终止

### 添加指令

当 Agent 暂停时，您可以输入指令引导 AI：

```
> 优先修复登录验证的 Bug
```

---

## 日志查看

- **滚动**: 查看历史输出
- **搜索**: Ctrl+F 搜索关键字
- **清空**: 右键菜单清空终端

---

## AI 自动命名

启用 Settings → "AI Terminal Naming" 后，终端会根据内容自动生成描述性名称。
