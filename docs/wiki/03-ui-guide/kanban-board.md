# 看板视图 (Kanban Board)

看板是 Auto-Claude 的核心工作区，用于管理任务生命周期。

---

## 界面布局

```
┌─────────────────────────────────────────────────────────────────┐
│  Backlog   │  In Progress  │  AI Review  │  Human Review  │ Done │
├────────────┼───────────────┼─────────────┼────────────────┼──────┤
│ 待办任务   │   运行中      │  AI 审查    │   待您批准     │ 完成 │
│            │               │             │                │      │
│ [任务卡片] │  [任务卡片]   │ [任务卡片]  │  [任务卡片]    │[...]│
└────────────┴───────────────┴─────────────┴────────────────┴──────┘
```

---

## 任务卡片

每张任务卡片显示：

| 元素 | 说明 |
|------|------|
| **标题** | 任务描述的摘要 |
| **状态标签** | 运行中 / 需要审查 / 完成 等 |
| **进度指示** | 规划 → 编码 → QA 的阶段进度 |
| **操作按钮** | 开始 / 停止 / 查看详情 |

---

## 任务状态流转

```
Backlog → In Progress → AI Review → Human Review → Done
   ↑                        ↓
   └─────── QA 失败修复 ────┘
```

### 状态说明

| 状态 | 含义 | 用户操作 |
|------|------|----------|
| **Backlog** | 待开始 | 点击"开始" |
| **In Progress** | AI 工作中 | 观察或中断 |
| **AI Review** | QA 验证中 | 等待 |
| **Human Review** | 需要您批准 | 合并/丢弃 |
| **Done** | 已完成 | 可归档 |

---

## 拖放操作

您可以通过拖放任务卡片来手动调整状态：

- ✅ Backlog ↔ 任意状态（重新排序）
- ✅ Done → Archive（归档）
- ❌ 无法跳过 AI Review 直接到 Done

---

## 批量操作

- **归档所有完成**: 点击 Done 列上的归档按钮
- **显示已归档**: 点击"Show Archived"查看历史任务
