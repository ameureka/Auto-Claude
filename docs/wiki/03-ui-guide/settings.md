# 设置页面 (Settings)

设置页面用于配置 Auto-Claude 的各项功能。

---

## 应用设置

### 外观

| 设置 | 选项 |
|------|------|
| 模式 | 浅色 / 深色 / 跟随系统 |
| 颜色主题 | 多种配色方案 |
| 缩放 | 75% - 200% |

### 语言

支持的语言：
- English
- Français
- **简体中文** ✨

---

## 认证配置

### Claude 账户

添加多个 Claude 账户以在速率限制时自动切换：

1. 点击 **"Add Account"**
2. 运行 `claude setup-token` 获取令牌
3. 粘贴令牌并保存

### 自动切换

启用后，当一个账户达到限制时自动切换到另一个：

| 设置 | 推荐值 |
|------|--------|
| 会话阈值 | 95% |
| 每周阈值 | 99% |
| 检查间隔 | 30秒 |

---

## 开发工具

配置首选的 IDE 和终端：

| 工具 | 用途 |
|------|------|
| IDE | 打开工作树查看代码 |
| 终端 | 打开外部终端会话 |

Auto-Claude 会自动检测已安装的工具。

---

## 代理配置

### 默认模型

选择任务使用的 Claude 模型和思考级别：

| 阶段 | 推荐模型 |
|------|----------|
| 规划 | claude-opus-4 |
| 编码 | claude-sonnet-4 |
| QA | claude-sonnet-4 |

---

## 通知

| 事件 | 默认 |
|------|------|
| 任务完成 | ✅ 开启 |
| 任务失败 | ✅ 开启 |
| 需要审查 | ✅ 开启 |
| 声音 | ❌ 关闭 |
