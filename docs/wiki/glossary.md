# 术语表

Auto-Claude 中使用的专业术语解释。

---

## 核心概念

| 术语 | 英文 | 说明 |
|------|------|------|
| **任务** | Task | 用户定义的开发目标 |
| **规格** | Spec | 任务的详细规格文档 |
| **代理** | Agent | 执行任务的 AI 实体 |

---

## 界面元素

| 术语 | 英文 | 说明 |
|------|------|------|
| **看板** | Kanban | 任务管理视图 |
| **终端** | Terminal | 代理输出界面 |
| **工作树** | Worktree | Git 隔离工作区 |
| **洞察** | Insights | AI 对话功能 |
| **路线图** | Roadmap | 产品规划视图 |

---

## 工作流阶段

| 术语 | 英文 | 说明 |
|------|------|------|
| **规划** | Planning | 制定实现计划 |
| **编码** | Coding | 编写代码 |
| **审查** | Review | 代码质量检查 |
| **修复** | Fixing | 修复发现的问题 |
| **合并** | Merge | 合并到主分支 |
| **丢弃** | Discard | 放弃更改 |

---

## 技术术语

| 术语 | 说明 |
|------|------|
| **MCP** | Model Context Protocol，AI 工具扩展协议 |
| **OAuth Token** | Claude 认证令牌 |
| **API Key** | Anthropic API 密钥 |
| **Graphiti** | 跨会话记忆系统 |
| **E2E 测试** | 端到端用户界面测试 |

---

## 状态标签

| 标签 | 含义 |
|------|------|
| 运行中 | AI 正在工作 |
| 需要审查 | 等待用户确认 |
| 已完成 | 任务成功完成 |
| 卡住 | 遇到问题需要干预 |
| 速率限制 | 达到 API 使用限制 |
